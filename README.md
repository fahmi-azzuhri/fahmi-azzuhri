### Manuknest

![Manuknest app preview](https://github.com/user-attachments/assets/a7f5e9b2-bae6-4391-8e4c-7395322546f2)

Manuknest is a personal archive for saving links and finding them again. Search and
filter your saved links, add notes and collections, and share selected links in
Explore. Link contents are encrypted in the browser before being sent to the Go API.
The app is also available as an Android app built with Capacitor.

[Explore the Manuknest repository](https://github.com/fahmi-azzuhri/manuknest).
